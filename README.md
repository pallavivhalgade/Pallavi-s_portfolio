# Pallavi Vholgade — Portfolio

**Live portfolio: https://pallavi-portfolio-preview.vercel.app**

AI & Machine Learning engineer based in Pune, India.

This repository contains the updated static portfolio: introduction and interactive portrait, About and education, four project feature stories, experience, a single flowing wall of 39 technology logos, an interactive 3D playground, and contact links.

## Features

- Responsive layouts for desktop, tablet, and mobile
- Distinct dark and light themes
- Contour and orbital live wallpapers with pause and reduced-motion support
- Full-colour, locally hosted technology assets with shared CSS 3D interactions
- Project filters and accessible project detail dialogs
- Direct links to LinkedIn, GitHub, email, and the résumé

## Run locally

Serve this directory with any static HTTP server, for example:

```sh
python -m http.server 8000
```

Open http://localhost:8000. All paths are relative and support GitHub Pages project hosting.
